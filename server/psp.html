Welcome to the PSP Web File Browser

About This Application

You are viewing this page from your PSP Web File Browser application. This homebrew app enables your PSP to browse web pages and download files over Wi-Fi.

Features

  • View web pages directly on your PSP
  • Browse available files from the server
  • Download files directly to your PSP memory stick
  • Simple and intuitive menu navigation

How to Use

Main Menu:

  • Use D-Pad Up/Down to navigate menu options
  • Press X to select an option
  • Press Circle to exit or go back

File Browser:

  • Browse available files from the server
  • Select a file and press X to download
  • Files are saved to ms0:/PSP/GAME/
